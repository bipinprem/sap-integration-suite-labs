# SAP Integration Suite Labs

Hands-on SAP Integration Suite (Cloud Integration) labs by Bipin Premachandran, built on a BTP trial tenant using the public Northwind OData service. No client or employer data is used.

| Lab | iFlow | What it shows |
| --- | --- | --- |
| [Lab 2 – Robust error handling](labs/lab2-robust-error-handling.md) | L2_Customer_Orders_Robust | Input validation (400), chained OData lookup with not-found handling (404), exception subprocess returning a reference ID (500) |

## Tools
SAP Integration Suite (Cloud Integration), Groovy, OData V2, OAuth 2.0 client credentials, Postman.
